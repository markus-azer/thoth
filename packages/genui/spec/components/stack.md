# Stack component

Vertical layout that holds the other components.

## Rules

- [RULE-STACK-001] A `Stack` with no children is invalid.
- [RULE-STACK-002] A `Stack` with more than 6 children is invalid.
- [RULE-STACK-003] A `Stack` can only hold a `Suggestions` or a `Link`.
